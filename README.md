# GRIP-V project page

Source of the project page for *Watch, Don't Glance: A Procedurally Generated Video Benchmark for Temporal Geometric and Physical Reasoning* (GRIP-V).

- `index.html`, `assets/style.css`, `assets/app.js`: the page (no build step).
- `assets/data.js`: results and example questions, generated from the paper's result files.
- `assets/clips/`: clip 000000 of eight sub-benchmarks, as released.
